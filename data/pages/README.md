# 홈페이지 안내 페이지 (RAG 원본 — 공지·학칙과 별개)

학교 홈페이지의 안내 페이지(수강신청·휴학·장학·학생증 등)를 `python scripts/scrape_pages.py`로 가져와 저장하는 폴더입니다 (작업 1-4a).

| 파일 | 내용 |
|---|---|
| `sources.json` | 수집할 페이지 목록 (tier 1=학사안내 메뉴·FAQ, tier 2=대학생활·시설) |
| `<slug>.md` | 페이지 본문(마크다운). 맨 위 `---` 사이에 출처 주소·수집 시각·`status` |
| `_state.json`·`_report.md` | 수집 결과 요약 — **`_report.md`의 "사람이 확인·입력할 페이지"를 보세요** |
| `manual/<slug>.md` | **사람이 직접 넣는 내용** — 있으면 사이트 추출보다 우선 |

## 사이트에서 못 가져오는 페이지 (학사일정·조직도처럼 화면이 열린 뒤 채워지는 곳)
1. 사이트 화면을 열어 내용을 복사해 `manual/<slug>.md`에 붙여넣기 (맨 위에 `# 제목` 한 줄). 표는 그대로 붙여도 됩니다
2. 복사가 어려우면 스크린샷을 Claude에게 주면 `manual/<slug>.md`로 옮겨 적습니다
3. `python scripts/scrape_pages.py --slug <slug>`를 다시 돌리면 `<slug>.md`로 반영됩니다

임베딩할 때는 `status`가 `ok`인 파일만 씁니다 (`short`는 내용을 확인한 뒤 사용).
