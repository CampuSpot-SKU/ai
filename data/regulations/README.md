# 학칙 원본 (1-4b)

`hakchik-YYYYMMDD.txt` = 학교 학칙 PDF를 `pdftotext -layout`으로 뽑은 글 (파일명 날짜 = 시행일).
PDF 자체는 올리지 않는다(출처: 학교 홈페이지 규정 페이지, 공개 자료).

- 현재: `hakchik-20261001.txt` (2026.10.1 시행 학칙, 조 123개 중 삭제 11개 제외 112개 적재). 기준은 2026학년도 요람(학교 홈페이지, 2026-04-16 게시) 37~76쪽의 2026.2.1 시행 학칙이고, 그 뒤 학교 공지로 올라온 학칙 일부개정안 5건(2026.4.1·5.11·6.1·9.1·10.1 시행)을 적용했다. 2026.2.1에서 바뀐 조: 제43조의2(심화전공 72→60학점)·제44조~제45조(전공 명칭)·제54조·제57조·제89조의2, 제45조의2(연계전공) 삭제. 2026.4~10 개정: 제2조·제4조(국방경영대학원·뮤지컬영재교육원), 제28조(휴학), 제32조(퇴학→자퇴), 제35조의2·3, 제43조의2, 제44조~제45조(세부사항은 별도로 정한다), 제44조의4(마이크로디그리전공) 신설, 제74조. 이전 판(20251001, 20260201)은 지웠다.
- 파서: `ai/regulations.py` (제N조 단위, 장·절·조의2 처리, 부칙·별표·서식 제외)
- 적재: Actions → "Embed pages" → target = regulations (check → apply → search)

## 학칙이 개정되면 (사람이 하는 일)
1. 새 학칙 PDF를 받아 `pdftotext -layout 파일.pdf hakchik-새시행일.txt`로 변환해 이 폴더에 넣는다.
2. push 후 Actions에서 target = regulations, action = apply — **바뀐 조만** 다시 임베딩된다(폴더에서 날짜가 가장 늦은 파일을 쓴다).
3. 새 파일이 시행일이 다른 새 판이면 옛 파일은 지워도 된다. 옛 조가 사라졌다면 `remove_missing`를 켜고 apply.

개정 사전공고·공포는 학교 공지로 올라오므로 답변 때 공지 검색으로 함께 안내한다(1-4c).

### 무엇을 반영하나 (10/15 결정)
- **시행·공포된 본만** 교체한다. 사전 공고 단계의 개정안은 확정 전이라 본문에 반영하지 않는다(오답 방지). 사전 공고는 답변 끝 안내("의견 수렴 단계, 확정 아님")로만 알린다.
- 공포 공지가 올라오면(제목에 "공포") 새 시행본 PDF를 받아 위 절차로 교체한다. 교체하면 기준일이 새 날짜로 바뀌어 그 이전 공지는 더 이상 안내되지 않는다.
- 확인 방법: 학교 홈페이지 규정 페이지(대학규정집)의 PDF·요람과 공지 중 "공포" 글. 10/15 확인: 규정집은 2024 제15회가 최신(적재본과 글자까지 동일), 학칙은 요람(2026-04)에 2026.2.1 시행 개정이 있어 교체했고, 그 뒤 공지의 학칙 일부개정안 5건(2026.4~10 시행)도 적용함(공포 공지는 학교가 올리지 않아 시행일이 지난 개정안은 확정된 것으로 봄 — 교무과 확인 필요). 학교가 현행 전문을 공개하지 않으므로 새 개정안이 올라오면 같은 방식으로 `hakchik-새시행일.txt`를 만든다

## 규정집 (1-4d)
`gyujeongjip-YYYYMMDD.txt` = 학교 규정집 PDF(학칙 외 230여 개 규정)를 `pdftotext -layout`으로 뽑은 글 (파일명 날짜 = 규정집 기준일).

- 현재: `gyujeongjip-20240901.txt` (2024.9.1 기준 + 아래 패치, 규정 225개 / 조 3,417개 적재, 삭제 조 제외)
- **10/15 패치(공지의 시행세칙 개정을 손으로 반영)**: ① 수강신청에 관한 시행세칙(2024.12.1 폐지 공포 확인)과 융합전공·자기설계전공·연계전공에 관한 시행세칙(2025.10.1 폐지 사전공고, 학칙 2026.2.1 개정과 맞물려 폐지로 처리)은 제목 아래에 `폐지` 줄을 넣어 적재에서 뺐다. ② 2026.9.1 개정: 편입학 제5조, 국내 교류대학 제6·7조, 계절학기 제1조, 사회봉사활동 제5조 — 본문을 고치고 이력에 `2026. 9. 1`(연도 4자리)을 붙였다. ③ 이력에 기준일보다 늦은 4자리 연도 날짜가 있는 조는 칩에 `2026.9.1 기준`, 머리말에 `2026.9.1 개정 반영 · 2024.9.1 기준 규정집`으로 표시된다(`regulations.latest_revision`). ④ 아직 못 넣은 것: 편입학 시행세칙 [별표 2](2026.6.1 시행, 130학점 기준 추가) — 별표는 적재하지 않는다. 수강신청·융합·자기설계·연계·다전공 규정 본문은 학교가 공개하지 않아 없다(교무과 요청 필요).
- 학칙 본문은 위 `hakchik-*.txt`로 따로 적재하므로 규정집 안의 "서경대학교 학칙"은 건너뛴다.
- 조 끝의 제·개정 이력 괄호 `(개정 2017. 9. 1 …)`·`(신설 …)`은 임베딩에서 뺀다(`(삭제 …)`는 유지).
- 모든 청크 머리말에 `2024.9.1 기준 규정집`이 붙고, 답변 칩에는 `2024.9.1 기준`이 표시된다 — 규정은 공지로 일부만 개정되기 때문.
- 파서: `ai/regulations.py`의 `parse_book` (쪽 머리글·바닥글 제거 → 규정명 인식 → 규정별 조 단위로 분리)
- 적재: Actions → "Embed pages" → target = regulations (check → apply → search). 학칙과 규정집이 함께 처리된다.
- `제N조` 직접 검색: 질문에 규정 이름이 있으면 그 규정에서, 없으면 학칙 본문에서만 찾는다.

### 규정집이 새로 나오면
1. 새 PDF를 `pdftotext -layout`으로 변환해 `gyujeongjip-새기준일.txt`로 넣는다(폴더에서 날짜가 가장 늦은 파일을 사용).
2. push 후 target = regulations, action = apply — 바뀐 조만 다시 임베딩. 사라진 조는 `remove_missing`를 켜고 apply.
